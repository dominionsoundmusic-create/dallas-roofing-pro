# Images still needed (Artistly)

Generated by `python3 build.py`. Maurice's rule: reuse first. Every page already uses the 15 DFW photos
and the generic roof photos reused from the Houston build (docs/photos.json). The images below are the
only new ones still wanted. Each one already has its final tag on the page (file name, width, height,
lazy loading in the body, eager loading and a preload for heroes), and until it is saved the build
shows a crop of an existing photo under the same file name (docs/image-reuse.json, column Stand-in),
with that photo's alt text, so nothing is ever broken or empty.

To add one: generate it from the prompt, save it as a JPEG under the exact file name and size in
`src/static/images/`, give it its alt text in the page source if needed, run `python3 build.py`, commit.

Style for every image: bright, clearly visible, North Texas homes and roofs (brick and stone two-story
and ranch houses, asphalt shingle, metal and flat roofs, live oaks, cedar elms and pecans, flat to gently
rolling prairie), natural daylight, no text, no logos, no watermarks, no recognizable faces. Every prompt
starts with: wide cinematic landscape shot, subject positioned on right third of frame, well lit.

Total: 13 images (11 heroes at 1920x1080 listed first, then 2 in-body images at 1200x800).
